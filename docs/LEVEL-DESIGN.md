# 两关与单位机制设计

状态：2026-09-16 已落地。只保留 **教学关（长坂逃命）** 与 **BOSS 关（江津抢渡）**，第二关「山道设伏」删除。数值进 `assets/game/balance.js`，内容进 `content.js`，判定进 `engine.js`，不在别处另存一套。

## 一句话

这是一场逃跑。追兵始终差一步咬到刘备，玩家扔拒马、下操作，把人再甩开一点，勉勉强强送到终点。所有道具只回答「怎么把距离再拉开一点」，所有敌人行为只看「离刘备多远」。不是守塔，不是歼灭，不是分兵包围。

## 共同规则

- 核心目标始终是护送刘备逃脱。抓捕后可营救；敌人把刘备送到当前失败点才判负；击败敌将不是通关条件。
- 同种单位跨关属性一致，不随关卡、失败次数、账号积累偷偷增强。没有金币升级、品质加成、数值词条。
- 六格编队。武将、兵种、消耗器械、计策争夺相同编队位；关卡机关属于地图，不占编队位。
- 我方普通攻击自动执行。张飞、关羽、诸葛亮的技能由玩家点击已上阵武将的底部卡牌释放，须有合法目标才进冷却；拆卸、阵亡、重新部署不重置本局冷却。三位武将各限一名。
- **刘备的脚底抹油是手动技能**：3 秒、2.4 倍速、冷却 30 秒，开局可用；被扛着、骑马时不可用；没有无敌。底部卡牌栏最左固定一个**圆形**刘备头像按钮，与长方形单位卡区分；显示冷却环，可用发亮，不可用变灰。删除进楼梯自动触发。
- 部署时展示作用方向和覆盖区域。滚木在拖放松手时按滑动方向决定滚向；固定方向器械可在落点预览选朝向，上阵后可在单位菜单转向。
- 普通攻击与地图伤害不伤友军；强制位移沿当前道路，不穿楼层。受击或眩晕不自动解除扛人，除非明确写有营救效果。
- **扛人的敌人和普通追兵一样被拒马、守军阻挡**，停下来打它；速度 0.85 倍，不冲刺。打死扛人者，刘备当场落地、继续向前跑，没有营救无敌。其余追兵替扛人者清路。
- BOSS 关敌人的出场与技能由 **追兵与刘备的距离** 决定，不由时间、进度百分比决定。教学关保留最简单的固定出场。
- 追兵总数有限，放完为止。抓捕不刷新波次，不重复触发机关。

## 教学关：长坂逃命

定位：教学。教三件事：拒马放在追兵和刘备之间；弓箭手隔着拒马射；把刘备送到的卢就能甩开追兵。短，能结束。

的卢在底层右侧楼梯旁；刘备碰到自动上马，以 `balance.js` 的倍率跑向终点。坐骑不占格、不花钱、每局一次；骑乘时脚底抹油不可用、不叠加。

| 阶段 | 出场 | 玩家学到什么 |
| --- | --- | --- |
| 村口 | 少量曹兵从唯一的后方入口出现，首队到达前有布防时间 | 拒马挡、弓箭手隔着射 |
| 楼梯 | 的卢在底层楼梯旁等 | 送到坐骑就甩开 |
| 山道 | 骑马驶向出口，不追加教学 | 快速结束 |

- 本关没有敌将、鼓手、飞贼、伞兵、侧门。不强制被抓、不强制用护驾；发生抓捕时才提示押送方向和营救。
- 脚底抹油按钮照常显示，本关不讲解；玩家自己按不影响教学。
- 胜利：刘备抵达山道出口。失败：扛人者把刘备送回村口入口。
- 新档提供弓箭手、拒马、长枪兵、滚木、张飞；赵云护驾是全局一次性按钮，不占卡位。
- 教学关仅首次通关发金币；失败、重玩、补勋章不发。首通解锁 BOSS 关和其余全部单位。
- 可行解法：拒马配弓箭手；长枪兵配张飞；分段布防配滚木救急。都用新档固定资源验证。

## BOSS 关：江津抢渡

主题：一场跑。追兵始终差一步咬到刘备，玩家用拒马、滚木和技能把人再甩开一点，勉勉强强送上船。本关不是守码头、不是分兵守两口、不是击杀夏侯惇。

### 一条原则

本关所有敌人行为由 **追兵与刘备的距离** 决定，不由时间、不由进度百分比决定。没有 `at`、`gap` 秒、`defenseAt` 这类计时触发。玩家用道具买出距离，距离变大就有新压力贴回来，距离收紧就没有新增援——压力永远跟在刘备身后一格，不会因为玩家守得好而变成散步，也不会因为守得差而同时来三拨。

距离用格计（一格 = `GRID_SPACING`）。取「刘备身后最近的、未被阻挡、目标为抓捕的地面追兵」到刘备的路线距离，记为 **咬距**。

| 咬距 | 状态 | 敌人做什么 | 玩家该做什么 |
| --- | --- | --- | --- |
| ≤ 0.5 格 | 咬住 | 飞贼冲刺；领头者碰到刘备即抓捕，没有任何自动保护 | 扔滚木 / 张飞怒吼 / 东风 / 脚底抹油，把这一步抢回来；手里没东西就是被抓 |
| 0.5–1 格 | 贴身 | 正常追击，路上有守军就打守军 | 在刘备身后一格补拒马 |
| 1–2 格 | 差一步 | 正常追击；夏侯惇在此距离且中间无阻挡时发动冲锋 | 长枪架枪、拒马挡冲锋 |
| > 2 格 | 拉开 | 鼓手击鼓、曹洪举旗；释放下一组增援，从刘备身后最近的入口出发；伞兵在刘备前方 1.5 格落地拦路 | 别停手，钱要跟着他跑 |

增援只在「拉开」时释放，一次一组。上一组还在出兵、还在空中、或还挡在刘备前面时不放下一组。咬距只看没被挡住的追兵：拒马把路挡住就是拉开，下一组必须贴回来，不能因为守得好就只出第一组。追兵总数有限，放完为止。刘备被抓时不释放增援。

追兵速度是刘备的两倍。刘备身后没有守军和拒马时，追兵几秒内就能贴上并抓捕。抓捕不是安排好的事件，是玩家钱、冷却或手速用空的直接后果；失败点就在身后几步，抓住后很快结束，重跑成本低。

### 抓住之后

- 扛人者和其他追兵一样被拒马、守军挡住，停下来打它；速度 0.85 倍，不冲刺。在他和当前失败点之间补一个拒马，就是营救口。
- 其余追兵改为替扛人者清路，打路上的拒马和守军；路清了才跟着走。
- 打死扛人者，刘备在原地落地，立刻继续向前跑；没有无敌，身后的人照样能再抓。
- 滚木方向由拖放时的滑动方向决定；刘备被扛时默认方向是把扛人者推离失败点。方向推反了会帮敌人押送，这是玩家的责任。
- 关羽钩镰刀勾离刘备最近的敌人，扛人者优先，把他拽回关羽面前。
- 赵云护驾落地解除扛人；眩晕从 5 秒降到 2 秒，不再顺手清场。
- 曹操例外：他抓住即判负，没有押送段。

### 场景与入口

三段折返路径不变：临江街道、沿岸栈道、渡口码头。入口共三处，都是刘备身后的点，失败点跟随最近入口一起往后挪：

- **街口**：底层起点。开局唯一入口，扛人者送到这里判负。
- **登岸口**：中层右端（原曹彰右门）。刘备走上中层并拉开一次后，曹彰敌船靠岸、开口；之后地面增援从这里出发，扛人者改送这里。开口前有靠岸预警，且刘备或扛人者距离登岸口不足 `safeDistance` 时不开。
- **栈道口**：顶层左端楼梯口。刘备走上顶层并拉开一次后开放；最后一组从这里出发，扛人者改送这里。

入口越往后，被抓后扛回去的路越短。曹操规则不变：进度过半从街口出生，抓住即判负，不能被震晕和击退。

### 追兵组成

敌人总数与原设计相当，不乘 1.3。本关没有盾兵、落石、木偶——盾兵是挡箭打仗的单位，不是追兵。鼓手和曹洪保留：他们的技能都是让队伍追得更紧，触发条件改成看距离。

| 组 | 出发点 | 组成 | 这一组的作用 |
| --- | --- | --- | --- |
| 街口第一组 | 街口 | 曹兵 ×3 + 夏侯惇 | 建立咬距；夏侯惇教「冲得停」 |
| 街口第二组 | 街口 | 曹兵 ×2 + 鼓手 ×1 | 第一次拉开后击鼓贴回 |
| 登岸组 | 登岸口 | 曹洪 + 曹兵 ×1 + 飞贼 ×2 | 入口后移；曹洪点飞贼当抓捕手，其余替他清路 |
| 拦路伞兵 | 刘备前方 1.5 格 | 伞兵 ×2 | 挡跑道，不抄阵地 |
| 栈道组 | 栈道口 | 飞贼 ×2 + 曹兵 ×1 | 上船前最后一口 |
| 跳板伞兵 | 码头跳板前 1 格 | 伞兵 ×1 | 最后一下必须清开 |

**夏侯惇**：只做一次冲锋。咬距 1–2 格且他与刘备之间没有守军或拒马时蓄力、冲向刘备；碰到刘备直接抓捕。被长枪架枪、张飞怒吼打断，或撞上拒马、滚木，则停顿 3 秒，之后按普通追兵速度追、不再冲锋。血条保留但不进 UI 的 BOSS 条；打死给金币，不要求打死。

**伞兵**：只在「拉开」时投放，落点在刘备前方 1.5 格、同层。落地前有预警，弓箭手射伞使其提前落地并短暂失衡。刘备在其落地前跑过落点，它落地后转为身后追兵。落在前面的伞兵不动，原地拦路、抓路过的刘备；必须用滚木推开、张飞 / 弓箭手清掉、东风吹开，或者射伞让它落在身后。

**飞贼**：咬住时冲刺；拉开时组里的飞贼先出发贴回。扛人时不冲刺。

**鼓手**：咬距进入「拉开」时击鼓，同组提速 1.2 倍，直到咬距回到「差一步」以内。咬住、贴身时不击鼓。击鼓过程可被打断，打断这次就不提速。鼓手是「拉开后贴回」的主要手段，新增援是第二手段。

**曹洪**：咬距进入「拉开」且刘备未被抓时举旗，把同组最快的一名（优先飞贼）点为抓捕手；其余人不再各自追刘备，改为清掉抓捕手前方的拒马和守军。抓捕手被打死或旗到时，全组恢复各自追击。曹洪本人不冲、不抓，打死给金币，不要求打死。

### 船

接应船开局就停在顶层出口，不需要等。刘备跑到跳板即登船获胜，没有蹲下、没有倒计时、没有防守阶段。最后一段的压力来自身后栈道组和跳板前的伞兵：清开跳板、身后再补一截，人才能上去。

### 军饷

开局 220（180 + 本关 40），够两个拒马加一名张飞或长枪兵。每秒恢复 4 不变。开局不够铺满一层，钱必须跟在刘备身后一格一格花。击杀奖励照旧，但本关经济不靠击杀撑。

### 道具在这一关的意义

每个道具只回答一个问题：怎么把咬距再拉开一点。

| 道具 | 买到什么 |
| --- | --- |
| 拒马 | 一组追兵啃 240 血，大约买刘备一格路；被扛时是营救口 |
| 滚木 | 把贴身的一组整体推退半格并打断冲刺，救「咬住」；方向自己定 |
| 长枪兵 | 站在拒马后面接冲锋，夏侯惇撞停 |
| 张飞 | 怒吼定住身后一群 2 秒，是最贵的一次「再等一下」 |
| 诸葛亮 | 东风把身后一群吹退一格并减速；吹偏未落地的伞兵 |
| 关羽（钩镰刀） | 把离刘备最近的那个拽回来，扛人者优先 |
| 弓箭手 | 射领头飞贼、射伞让伞兵落在身后 |
| 烟幕罐 | 追兵按最后看见的位置追，买一段错路 |
| 震军铜锣 | 改为把本层追兵整体推退一格，不眩晕 4 秒；一次 |
| 赵云护驾 | 救人不变；落地眩晕从 5 秒降到 2 秒，不再顺手清场 |
| 脚底抹油 | 手动，3 秒拉开约一格半；30 秒冷却，按错就没有下一次 |

本关推荐编队：拒马、长枪兵、滚木、张飞、弓箭手、诸葛亮。关羽、刀盾兵、连弩车、投石车可自选，不进推荐。局内升级保留，不在本关引导。

### 界面

- 底部卡牌栏最左侧固定圆形刘备头像按钮：脚底抹油。护驾按钮保持现有位置。
- 相机默认跟随刘备。玩家手动平移后停止跟随，3 秒无操作自动跟回。
- 进度条上除现有的「曹」标记，增加「最近追兵」标记，随咬距移动。
- 顶部咬距提示：`追兵 · 差 1.5 格`，≤ 0.5 格变红、震动一次。刘备被扛时改为 `离登岸口 · 还剩 2 格`。
- 夏侯惇冲锋、伞兵落点、入口开放的预警都指向刘备所在位置，不指向玩家阵地。

### 判定标准

- 一局正常通关中，咬距在「差一步」及以内的时间应占大半；出现「拉开」超过两次说明增援贴回不够快。
- 「咬住」时有钱、有冷却就该救得回来；没有就被抓。如果玩家可以提前铺满墙、全程不用救，说明钱给多了；如果攒着钱也救不回来，说明追兵贴回太快。
- 普通玩家一局应发生 1～2 次抓捕并有机会救回；零抓捕留给勋章。
- 通关时场上仍有活着的追兵是正常结果。击杀数不是本关的评价指标。
- 夏侯惇被打死、伞兵在空中被全部射落，都不应成为通关必要条件。

## 我方单位

已删除：火油、绊马索、连弩兵、投石兵。每个单位一个不可替代的动词。

| 单位 | 核心机制 | 限制与代价 | 用途 |
| --- | --- | --- | --- |
| 刘备 | 自动沿路线逃跑；脚底抹油手动（3 秒、2.4 倍、30 秒冷却），圆形按钮在卡牌栏最左；被抓后改变押送方向 | 不攻击，不穿过抓捕者，加速不是无敌，被扛时按不出 | 玩家围绕他的移动布防，不能只守出生点 |
| 弓箭手 | 抛射越过友军阻挡；优先射正在下降的伞兵，射破伞使其提前落地并短暂失衡 | 贴身后需要别人保护；射伞不直接秒杀伞兵 | 射领头飞贼、让伞兵落在身后 |
| 长枪兵 | 无敌人贴身时架枪；首次迎击冲锋使其停下，随后须重新架枪 | 贴身缠斗时不能架枪；转身需重新准备 | 拒马之后架枪，防飞贼和夏侯惇 |
| 刀盾兵 | 正面架盾拦下一次普通攻击，随后重整空窗；可与相邻普通兵换位 | 背面无盾；换位后必须重整 | 可选。在入口后移时换前后排 |
| 张飞 | 手动怒吼：打断蓄力、让范围内追兵停步 2 秒，自身短时减伤 | 只作用身边；用在杂兵上可能错过夏侯惇 | 咬住时的一次「再等一下」 |
| 关羽 | 手动横扫同侧扇区。装钩镰刀后改为：勾住离刘备最近的敌人（扛人者优先），拉离刘备、拽到自己面前 | 只管自己这一侧；钩镰刀失去群体横扫 | 标准横扫清身后一群；钩镰刀是营救工具 |
| 诸葛亮 | 手动东风把同层区域内的敌人吹离自身一格并减速；吹偏未落地的伞兵 | 方向由站位决定；放错一侧会把扛人者推向失败点 | 买一格距离；处理拦路伞兵 |
| 赵云护驾 | 每局一次，落到刘备身边，解除扛人并眩晕周围 2 秒 | 不占卡位，用后本局不恢复；救出后依然要有人断后 | 最后一搏 |
| 拒马 | 阻挡地面敌人；友军可越障射击 | 不攻击；挡不住空中；夏侯惇冲击后可能失守 | 买一格路；被扛时是营救口 |
| 滚木 | 沿拖放方向滚动，推退地面敌人、打断奔跑与蓄力 | 只作用同层地面；方向推反会帮敌人押送 | 救咬住；推开拦路伞兵 |
| 连弩车 | 固定朝向直线穿透弩矢，打穿纵队 | 转向要撤下重布；无对空 | 可选。长通道纵队 |
| 投石车 | 长蓄力打固定落点，砸散集结并中断集结动作 | 近距盲区，弹道不追踪 | 可选。打鼓手、曹洪的集结 |

## 敌方单位

已删除：锅盖校尉（盾兵）。

| 单位 | 让玩家面对的问题 | 应对 |
| --- | --- | --- |
| 普通曹兵 | 追捕，抓到后由同伴清押送路线 | 身后补拒马；营救口断扛人者 |
