# 三关与单位机制设计

状态：2026-09-16 已接入三关、单位机制、战术装备与计策。运行数值以 assets/game/balance.js 为准，内容与判定以 content.js、engine.js、theme.js 为准；下文保留设计意图，当前验证范围见 BALANCE.md，未完成的独立卡面与机关精绘不计入本次逻辑交付。

## 共同规则

- 核心目标始终是护送刘备逃脱。抓捕后可营救，敌人把刘备送到明确的接收点才失败；击败敌将不是通关条件。
- 保留基础生命、伤害、费用、射程和冷却，用于保证动作能成立。不同关卡的同种单位使用同一基础规则，不随关卡、失败次数或账号积累偷偷增强。
- 已取消金币升级。已取消品质的伤害、控制百分比加成。宝箱改为武器特性、器械改装和计策；每个战术选项有明确代价，不设战斗强弱递增的品质阶梯。
- 六格编队继续保留。武将、兵种和消耗器械争夺相同编队位；关卡机关固定属于地图，不占编队位。
- 我方普通攻击自动执行。张飞、关羽、诸葛亮的主动技能由玩家点击已部署武将的底部卡牌释放；部署仍用拖拽。卡牌展示技能范围、状态与冷却，不增加全局能量条。
- 主动技能须有合法目标才进入冷却。拆卸、阵亡和重新部署不重置本局该武将的技能冷却，避免刷技能。三位武将仍各限一名。
- 部署时展示作用方向和覆盖区域。固定方向器械可在落点预览中选择朝向，部署后可通过单位操作菜单转向；普通兵种继续自动转身。
- 普通攻击与地图伤害不伤友军；强制位移沿当前道路进行，不穿楼层、不推落地图。受击或眩晕不自动解除扛人，除非明确写有营救效果。
- 敌人的新行为先单独示范，再与已学行为组合。首次冲锋、空降、侧面入场分别发生，按路线阶段推进并保留最小间隔，首次伞兵单独进入，不伴随额外地面队。
- 波次有限，抓捕不刷新波次、不重复触发机关与教学。营救后没有隐藏无敌；营救技能通过实际控制周围敌人创造逃离窗口。

## 第一关：长坂逃命

定位：教学关。前半程练习断后，中层道路中央放置的卢；主公碰到后自动上马，以基础速度五倍快速跑向终点。坐骑不占部署格、不消耗军饷，每局只领取一次，重开恢复；骑乘不叠加脚底抹油。

教学关仅在首次通关时发金币，失败、重玩通关和补勋章不发金币；关卡入口显示教学与领奖状态。任一关通关结算后默认选中下一关并保存，末关保持当前关卡；玩家可手动选择已解锁的旧关重玩。

场景沿用村口、长坂桥、山道三段折返，保留现有格子与拖卡交互。

| 阶段 | 出场与事件 | 玩家学到什么 |
| --- | --- | --- |
| 村口 | 少量普通曹兵从唯一的后方入口出现，首队到达前有布防时间 | 拒马放在追兵与刘备之间，弓箭手隔着拒马射击 |
| 长坂桥 | 的卢在道路中央等候，主公接触后换为骑乘形象并提速 | 护送到坐骑即可迅速甩开追兵 |
| 山道 | 骑着的卢驶向出口，不追加教学步骤 | 快速结束第一关 |

本关没有盾兵、鼓手、敌将、伞兵和侧门。第一关不强制刘备被抓，也不强制消耗护驾；实际发生抓捕时才提示押送方向与营救。

胜利：刘备抵达山道出口。失败：携带者将刘备送回村口入口。新档提供弓箭手、拒马、长枪兵、滚木、张飞；赵云护驾是全局一次性按钮，不占卡位。

可行解法：拒马配弓箭手；长枪兵配张飞；分段布防配滚木救急。每条路线都用新档固定资源验证，不要求抽箱。

## 第二关：山道设伏

主题：敌人开始配合，玩家用站位拆阵，用机关选择战斗地点。

仍为三段道路，场景换为山脚、隘口、山顶栈道。敌人仍从后方追来，本关不再新增侧门、空降或等待撤离规则。

| 阶段 | 出场与事件 | 玩家决策 |
| --- | --- | --- |
| 山脚 | 盾兵带普通兵出现；举盾朝向与盾后保护范围可见 | 用抛物线投石越盾，或控制破盾，再由弓弩输出 |
| 隘口 | 首次鼓手在后方集结队伍，击鼓准备过程清楚可见；开放一处落石机关 | 打断鼓手，还是等敌人聚集进入落石范围再放机关 |
| 栈道 | 曹洪携悬赏队登场，悬赏旗标记抓捕手；开放一具假主公木偶 | 对付抓捕手，或诱导他把木偶扛回去；留兵截断真实押送路线 |

地图机关：

- 落石：第二行固定机关向第一行同列垂直落下，一次使用，发动即消耗次数，空放同样消耗。点击前标出正下方落点；只在落地时伤害、眩晕该小范围内的地面追兵，不横向推动、不打第二行敌人。敌人在下落期间移出范围可躲开，也能砸中后来进入落点的追兵。具体范围、伤害、眩晕和下落时间统一取自 balance.js。
- 假主公：栈道固定诱饵点，一次启用。未抓住真人的普通兵或悬赏抓捕手会把木偶当作抓捕目标；敌将不会受骗，已经扛着真人的敌人不会换货。木偶被扛到敌军入口后识破消失，不影响真实胜负。
- 木偶所在位置与刘备路线错开，激活前展示受诱导范围；没有合适目标时不消耗使用次数。两处机关按地图阶段分别介绍。

胜利：刘备越过栈道出口。失败：被送回后方入口。曹洪可被击败，也可以被拖住后绕过；不靠必须击杀的血条延长关卡。

进入本关前固定解锁关羽、刀盾兵、连弩兵、投石兵、绊马索。可行解法至少覆盖越盾投石、控制破盾、机关诱敌三种路线，任何一名武将都不能成为唯一通关钥匙。

## 第三关：江津抢渡

主题：防线方向改变，最终需要为刘备争取登船时间。

场景为临江街道、沿岸栈道、渡口码头。保留三段折返路径，将原曹彰右门机制表现为敌船靠岸和登岸接收点。

| 阶段 | 出场与事件 | 玩家决策 |
| --- | --- | --- |
| 临江街道 | 夏侯惇带少量普通兵出现，先单独展示蓄力红线、冲撞和撞后停顿 | 用长枪架枪、绊马索或张飞打断；也可让拒马承受冲击，再利用停顿脱身 |
| 沿岸栈道 | 进入下一路线阶段后，曹彰敌船从远处驶来，靠岸预警后开放侧面入口 | 提前给新入口留防守位，在追兵和侧面拦截者之间分配军饷 |
| 渡口外侧 | 玩家有时间处理首批登岸兵后，首次油纸伞兵在标记点下降 | 用弓箭手提前射伞，或在落点布置控制；前线不能吃掉所有部署空间 |
| 码头 | 刘备首次进入等船区后开始固定接应倒计时，仅追加有限的最后一拨 | 保留救援和区域控制，守住码头，再救出被抓的刘备登船 |

本关不再叠加曹洪、鼓手、第二关落石和木偶。前三段各解释一个变化，最后一段才组合已出现的威胁。夏侯惇进入最后阶段时不再次复制生成。

侧门规则：曹彰驻守敌船、不追击、不占部署格。开门后新地面援军从登岸点出现，原入口停止新增援。所有携带者转向已标示的登岸接收点；开门前仍送往原入口。普通敌人或自由的刘备经过接收点不会失败。

预警安排：侧门不会在刘备或携带者身上突然开启；地图与波次必须留出拦截距离。不能把第一次空降安排在接收点旁边制造落地立即失败。

接应规则：首次进入等船区后只启动一次倒计时，被抓不重置；接应船靠岸后会等待。刘备自由到达登船点获胜，仍被扛走时必须先营救。倒计时结束不是失败条件。等待时长作为待实战验证的关卡参数，不在设计中伪称已经平衡。

进入本关前固定解锁诸葛亮、火油、连弩车、投石车。可行解法至少包含守口封路、前后夹击、预留机关营救三类；伞兵既能空中处理，也能落地处理。

## 我方单位职责

以下是单位职责；精确作用范围与状态时长由运行代码决定。每个单位一个主要用途，并明确什么时候不好用。

| 单位 | 核心机制 | 限制与代价 | 搭配或用途 |
| --- | --- | --- | --- |
| 刘备 | 自动沿路线逃跑，近身危险时触发短距离加速；被抓后真实改变押送方向 | 不攻击，不穿过抓捕者，加速不是无敌 | 玩家围绕他的移动提前布防，不能只守出生点 |
| 弓箭手 | 抛射越过友军阻挡，优先射击射程内正在下降的油纸伞兵；射破伞使其原地提前落地并短暂失衡 | 正面箭会被盾兵拦截，贴身后需要别人保护；射伞不直接秒杀伞兵 | 从第一关基础输出，成长为第三关对空选择 |
| 长枪兵 | 无敌人贴身时进入架枪状态；首次迎击冲锋使其停下，随后须重新架枪 | 贴身缠斗时不能再次架枪；转身也需重新准备；不会持续推退所有敌人 | 拒马之后架枪，防快兵与夏侯惇突破 |
| 刀盾兵 | 正面架盾拦下下一次普通攻击，随后露出重整空窗；可手动与相邻普通兵换位，把后排换到自己身后 | 背面不受盾保护；换位要放下盾且必须重整后才能再用，不能跨过敌人，双方保留生命与冷却 | 在侧入口出现时调整前后排，依靠护卫换位而非被动百分比减伤 |
| 连弩兵 | 自动优先锁定同层携带者，其次悬赏抓捕手；连续命中同一目标后短暂钉步 | 转换目标会重置连击；连射后必须完整装填；举盾能阻断连击 | 预先放在押送路线，争取营救时间；本身不自动释放刘备 |
| 投石兵 | 弧线落石能越过盾的正面防护，优先打盾后鼓手等支援目标 | 石块发射后落点固定，快兵容易跑开，贴身敌人也能逼迫其自卫 | 拆盾兵与鼓手组合，属于越盾点杀而非小号投石车 |
| 张飞 | 手动怒吼：打断蓄力、解除举盾，并让范围内追兵短暂停步 | 作用在自己附近；用来处理普通兵后可能错过下一次冲锋 | 路口断后或在关键一刻救场，核心是打断时机 |
| 关羽 | 手动横扫同侧扇区；掀开正面盾阵，为后续攻击制造窗口，普通挥击可扫到紧邻目标 | 只能扫自己这一侧，无法照顾背面与远处；单个散兵用不出阵形价值 | 拒马聚敌后横扫，再接连弩车直线穿射 |
| 诸葛亮 | 手动东风将选定同层区域内的敌人向远离自身的一侧推移，并吹偏该区域尚未落地的伞兵 | 方向由站位决定且提前展示；放错一侧可能把携带者推向接收点；不能跨层吹人 | 将敌人推回火油、落石区域，改变接战位置 |
| 赵云护驾 | 每局一次，全图跟随刘备落地，释放被抓的刘备并控制周围追兵 | 不占卡位，使用后本局不恢复；救出后依然需要有人断后 | 各种编队共有的紧急营救手段 |
| 拒马 | 阻挡地面敌人，制造聚集与集火位置；友军可通行和越障射击 | 不攻击，挡不住空中绕后；夏侯惇冲击后可能失守 | 是组织阵形的工具，而不是靠耐久独自解决所有追兵 |
| 滚木 | 沿选定方向滚动，推退地面敌人、打断奔跑与蓄力，打散押送队 | 只作用同层地面；不穿楼梯；推进方向错误也会帮助敌人押送 | 前方投下向后滚可以救急，也可把敌人推回火油 |
| 火油 | 在指定位置留下火区，使进入者失去举盾和架势，持续暴露；与位移配合延长接触 | 不直接定身，快兵能穿过；火区熄灭后恢复正常；不伤友军 | 先用阻挡定住，再持续破盾，重点是区域控制 |
| 连弩车 | 固定朝向发射直线穿透弩矢，一次打穿排成纵队的多个目标 | 转向必须撤下重布；完好的正面大盾会截住贯穿；无对空能力 | 依赖长通道、聚敌与破盾，区别于追踪携带者的连弩兵 |
| 投石车 | 长蓄力后打击固定落点，砸散集结阵形并中断范围内的集结动作 | 有近距盲区，弹道不追踪，零散快兵容易躲开，近身需保护 | 配拒马或停步控制处理成群敌人，区别于投石兵的越盾点杀 |
| 绊马索 | 首个踩中的地面敌人被绊倒，解除冲锋与举盾，随后消失 | 普通小兵也会提前踩掉，不认敌将；空中不能触发 | 摆在前排清掉杂兵后的关键路径，也可摆在伞兵落点 |

## 敌方单位职责

| 单位 | 让玩家面对的问题 | 至少两种应对 |
| --- | --- | --- |
| 普通曹兵 | 追捕，抓到刘备后由同伴清理押送路线 | 前方阻挡并输出；后方截断携带者撤退路线 |
| 草鞋飞贼 | 蹲身预警后沿道路冲刺，专抓防线空档；扛人时不再冲刺 | 架枪或绊马索截停；留滚木、张飞处理突破 |
| 锅盖校尉 | 面向目标举盾，拦截正面直射并保护紧随队友；转向时有破绽 | 投石越盾；张飞或关羽破盾；绕到背后射击 |
| 催命鼓手 | 敲鼓前集结附近同伴，完成鼓点后带队同时推进；本体被打断则本次集结失效 | 投石越前排打断；范围技能或落石打散集结 |
| 油纸伞兵 | 空中标出落点，落地后从防线背后追捕，不在空中抓人 | 弓箭手射伞或东风改落点；提前在落点布陷阱和阻挡 |
| 曹洪 | 举旗选定抓捕手，护卫转为替它清路，形成目标明确的抓捕队；不是单纯全队加速 | 连弩盯抓捕手、控制护卫；用假主公诱走抓捕手；截住曹洪使其不能继续发令 |
| 夏侯惇 | 预警后冲击路径上的第一处阻挡，撞击或被打断后停顿；冲锋不是无敌 | 架枪、怒吼或绊马索打断；用拒马承受冲撞，再趁停顿布防或逃离 |
| 曹彰与虎豹骑 | 驻守登岸接收点，改变援军入口及押送目的地，不设置必须打掉的驻守血条 | 提前控制入口；在接收点之前布置营救火力，截住携带者 |

普通伤害不是让鼓手、曹洪失去行动能力的自动打断；需要明示的控制或击败。盾牌只防正面直射，不凭敌方身份对所有伤害统一减半。敌将遵守对应的打断、停步、位移规则，不通过隐藏免疫否定玩家策略。

## 解锁、金币与界面

- 新档第一关提供五张基础卡；首次进入第二关、第三关前分别固定解锁对应单位。解锁按关卡 ID 保存，不重复发放、不依赖宝箱运气。
- 每关首进只推荐一个能应对核心机制的编队，玩家可自由调整已解锁单位。不用“战力不足”提示拦住出征。
- 宝箱提供下面定义的机制装备和计策。旧档已获得单位继续拥有，旧品质保留为收藏记录，不删除物品，也不继续提供百分比属性。基础单位与关卡必需对策按关卡稳定解锁，开箱增加可选解法。
- 详情先显示“能做什么／怕什么／如何配合”，下面保留费用、射程、冷却等实用信息；不显示战力、等级箭头或品质百分比增伤。
- 关卡选择展示本关主要威胁和地图机关。结算记录通关与挑战目标，不用奖励攻击力或军饷增长推动重刷。

## 金币宝箱：开出打法

宝箱内容分为三类：八种武将／兵种的机制武器、六种器械的改装、独立计策。首批设计 16 件武器、12 件改装、3 张计策，共 31 个不同的战术选项；总数由物品列表生成，不能在界面写死。

每个单位永久拥有不需开箱的「标准装备」，就是上表基础机制。每次出征最多选一个武器或改装，作用于本局同类型单位，不占额外编队位；换装备必须回营地。新特性替换对应行为，不与标准装备或另一个改装叠加。

### 武器：八类单位，每类两种侧重

| 对应单位 | 宝箱武器 | 改变的行为 | 明确失去的能力或风险 |
| --- | --- | --- | --- |
| 张飞 | 震门铁矛 | 怒吼变成朝向前方的直线震波，能沿通道依次打断与破盾 | 不再覆盖身边两侧，背后伞兵无法照顾 |
| 张飞 | 护阵蛇矛 | 怒吼改为挑衅，附近未扛人的普通敌兵暂时转攻张飞 | 不再眩晕或破盾；不能把已被扛走的刘备喊下来，不中断敌将冲锋 |
| 关羽 | 钩镰刀 | 技能勾住正面第一个地面敌人，向自身拉近并解除其举盾 | 失去范围横扫；拉错目标会把危险带到阵地，也可能帮助携带者接近接收点 |
| 关羽 | 旋锋偃月 | 技能改成围绕自身的近身回旋，能处理两侧贴近的敌人 | 失去向前延伸的扫击范围，必须等敌人靠近才有效 |
| 诸葛亮 | 回风扇 | 东风改为把选定区域内敌人聚到区域中心，方便落点攻击 | 不再把整队推离防线，也不吹偏空降；聚拢携带者可能缩短押送距离 |
| 诸葛亮 | 定风幡 | 东风改为在前方立一道短暂风障，拦住并打断下一名穿过者后消散 | 失去群体位移和对空；普通小兵可能先消耗风障 |
| 弓箭手 | 号令弓 | 命中目标挂上信号，附近友军在各自合法射程内优先集火该目标；携带者救援优先级仍最高 | 不再射伞；同一弓箭手只能维持一个信号，多个信号按最近命中选择，不叠加伤害 |
| 弓箭手 | 散羽弓 | 改为近处扇面分散射击，同时照顾聚在一侧的多个敌人 | 失去远射与对空，箭不穿盾；单个目标不会吃到多支箭叠伤 |
| 长枪兵 | 倒钩枪 | 不再架枪，改为勾住首次进入枪尖范围的地面敌人并向枪兵拉近，随后松钩重整 | 失去迎击冲锋，不能连续拖拽；拉近携带者需要选对站位 |
| 长枪兵 | 阵列枪 | 改为固定朝向的贯刺，能刺到首个敌人紧随其后的目标 | 不再自动转身或迎击截停；遭遇背后入场时容易失守 |
| 刀盾兵 | 捕索盾 | 盾面捕索拴住首个贴身的普通地面敌人，双方留在原地交战，绳索断开或一方阵亡后解除 | 失去换位护卫；同时来的其他敌人不被绳索拴住，敌将不会被套住 |
| 刀盾兵 | 折面盾 | 下一次架盾格挡可从两侧任意一侧触发，之后统一进入重整空窗 | 失去换位护卫，不能把旁边的脆弱后排换到安全位置；不是两侧各有一次额外格挡 |
| 连弩兵 | 猎旗弩 | 目标优先级改为鼓手、悬赏指挥者等支援单位；仍需完成连续命中才能钉步 | 放弃自动优先追射携带者，救援职责要交给别的单位 |
| 连弩兵 | 牵制弩 | 连续命中改为压制普通攻击，让目标短暂不能出手，但仍能走动 | 失去钉步，不能靠它阻止携带者撤退，也不打断敌将技能 |
| 投石兵 | 破鼓石兜 | 改为单点投掷，命中正在击鼓或举旗的支援单位会打断本次指挥动作 | 失去小范围溅射，对没有指挥动作的目标只有普通单点攻击 |
| 投石兵 | 撒石兜 | 投掷改为在固定落点留下碎石带，使经过的冲刺者失足停下后消散 | 不再直接砸伤敌人或优先狙击支援；慢行盾兵不触发，碎石不能无限铺满地图 |

同一单位的持续区域、信号或牵引只保留一个实例。不同单位的控制可以接力，但同类控制不累加时长；同一攻击不能重复触发同一装备效果。

目标选择先执行本单位装备写明的优先级，信号与铃铛只在相同优先级内引导集火，不让单位越过射程、朝向、盾牌或空地限制。猎旗弩放弃救援优先是明确例外，必须在装备卡上提示。

### 器械改装：改变使用方式

| 对应器械 | 宝箱改装 | 改变的行为 | 明确代价 |
| --- | --- | --- | --- |
| 拒马 | 捕兽架 | 捕住首个接触的普通地面敌人，使其留在原位攻击捕兽架 | 捕住后不再形成整条道路的阻挡，后续敌人可以通过；敌将不会被捕 |
| 拒马 | 折叠架 | 可手动放倒一次，再升起一次；可先放追兵过去，再升起拦住返回的携带者 | 放倒期间完全不能阻挡，升起有可见准备过程；每次部署不能反复切换 |
| 滚木 | 钩链滚木 | 去程经过敌人只造成碰撞，回程才把命中的敌人向投放点拖回 | 去程不能推退或打断，紧急使用可能来不及；每个敌人只受一次有效回程拖拽 |
| 滚木 | 碎木包 | 原地砸开，打断落点附近地面敌人的奔跑和蓄力 | 不再沿道路滚动或推移整队，远处敌人完全不受影响 |
| 火油 | 黏油桶 | 地面改为黏油，进入者不能启动冲刺，正在冲刺者恢复步行 | 不再燃烧、伤害或破盾；只是争取输出与调整时间 |
| 火油 | 火线罐 | 改为一条一次性火线，首个穿过者停步拍火并解除举盾，随后火线熄灭 | 放弃持续区域作用，普通曹兵就能消耗火线；不改变携带状态 |
| 连弩车 | 绞索弩 | 改为钩住正面第一个敌人，沿道路向弩车拖近，然后重新上弦 | 不再穿透队列，不穿过阻挡拖人，也不自动转向；放错位置会帮助敌人押送 |
| 连弩车 | 贯盾弩 | 改为击开正面首个敌人的举盾，为其他输出制造窗口 | 弩矢止于首个目标，放弃纵队穿透，不能一箭清理后方队伍 |
| 投石车 | 网兜弹 | 落点张网，使范围内敌人暂时不能移动，但仍可攻击、击鼓、举旗 | 失去爆炸伤害和集结打断；网落下前目标可能已经离开，需其他单位接应 |
| 投石车 | 碎石弹 | 落点留下碎石地形，让之后经过的敌人无法冲刺、队伍推进被拖散 | 失去瞬间砸散和直接伤害，对已在眼前的携带者不能立即营救 |
| 绊马索 | 响铃索 | 首个踩中者被挂上铃铛，附近友军优先追射它，适合押送路线 | 不再绊倒、破盾或中断冲锋；响铃不是额外伤害，且须有人能够射到 |
| 绊马索 | 连环索 | 两个敌人同时进入触发范围时才收紧，把他们一起绊倒 | 单独经过的快兵或携带者不会触发，使用位置依赖敌人队形 |

折叠架、定向弩车等需要操作的单位通过已有单位操作面板执行，并显示朝向和剩余操作次数。持续地面效果到时消失，同一来源再次释放会替换旧区域；这些限制来自机制定义，不按某一关特殊写死。

### 计策：占编队位的额外选择

计策获得后永久拥有，携带时占六格编队中的一格；用本局军饷发动，每张计策每局一次，重开恢复。没有账号库存消耗，也不能花营地金币在局内买次数。使用条件不成立时不扣钱、不消耗次数。

| 计策 | 效果 | 代价与限制 | 适合的场景 |
| --- | --- | --- | --- |
| 调兵令 | 选择一名未贴身交战的普通兵，令其沿已有道路转移到空部署格 | 转移时不能攻击，保留当前生命和冷却；武将、器械不能搬运，目标格途中预留，不能靠搬运回血或免受攻击 | 第三关侧入口开放前把旧防线的一名后排调过去 |
| 诱敌旗 | 在空格插旗，让范围内尚未抓人的普通敌兵优先走向它，旗被首次攻击后倒下 | 占一个部署格，不控制敌将和携带者；不强迫敌人穿过障碍，已启动冲锋不瞬间掉头 | 将普通兵引进落石或火油区域，改变接战位置 |
| 烟幕罐 | 指定区域起烟，区域内单位不能被远程锁定，也不能向外远程攻击；区域外普通追兵暂时按刘备最后可见位置追赶 | 近身仍能发现和抓捕刘备，不能救出已被扛走者；会妨碍己方射击，追兵不是停在原地 | 为刘备经过一段路争取调整时间，或让敌人继续追向错误位置 |

### 开箱与获得规则

- 先沿用每箱 50 金币。打开后展示至多三件不同的未拥有内容，玩家三选一；候选不足三件时按实际数量展示，不凑重复品。
- 武器与改装只从已经解锁的基础单位对应池中出现，计策可从第一关出现。新账号首箱不再随机保底武将，因为第一关的张飞已经稳定提供。
- 每件候选卡明确显示“改变什么／失去什么／适合谁”，不能只展示金光、颜色或攻击力数字。
- 开箱时扣费并保存候选；刷新、关闭、返回都继续同一箱。选择后只领取所选一件，另外两件回到未拥有池。存在待选箱时不能再扣费开下一箱。
- 当前可获得内容已经集齐时停止收费，显示下一个关卡会解锁的装备类别；不出售没有新选择的空箱。
- 不引入永久攻击、生命、军饷、冷却强化，不抽数值词条，不合成同名装备升星，不出售复活和护驾次数。
- 旧版已拥有的品质在转换时保留收藏记录；按每个不同的旧战利品记录赠送一张通用军需券，从已开放池的未拥有内容中三选一，可留到后续关卡。迁移领取状态持久化，重复刷新不重复赠送。

### 可直接感受到的装备组合

- 拒马聚敌 → 关羽标准横扫掀盾 → 标准连弩车贯穿队列。遇到盾兵不必拥有贯盾弩才能打。
- 号令弓标记危险对象 → 其他兵种集中输出；代价是这名弓箭手不能再负责射伞，需要落点防守补位。
- 回风扇把敌人聚拢 → 网兜弹罩住 → 留给弓箭手处理；失去标准东风的退敌能力，贴脸时更危险。
- 折叠拒马先放追兵通过 → 连弩兵守在后方 → 敌人抓到刘备返回时升起拒马，形成真正的营救口。
- 诱敌旗引走普通曹兵 → 连环索只处理后续聚集队伍；如果来的是单独快兵，这套组合就需要换回标准绊马索。

宝箱带来换打法的理由，不能成为通关门票。每关先用标准装备验证，再加入这些变体检查是否增加解法，以及是否存在没有代价的全面替代品。

## 实现边界与判定标准

- 保留当前单一路径、三段场景、驻守格与相机基础，不为这三关新增分岔寻路或复杂编辑器。
- 关卡定义统一包含路线、部署点、波次、阶段事件、地图机关、接收点、胜利条件和解锁；运行、UI 与结算从同一关卡定义读取，移除全局固定第一关入口与武将列表的依赖。
- 单位定义统一包含目标优先级、攻击形态、朝向规则和技能；单位详情从同一规则定义生成。渲染只展示结果，伤害、抓捕和营救由引擎结算。
- 第一关只使用列明内容，不能意外触发原先 50% 同时开门、空降和武将登场的逻辑。阶段触发只执行一次，不能因进度倒退重放。
- 相同编队与操作在相同关卡中不因旧档等级或品质产生强度差异；变强来自选择与操作。
- 每关以固定基础资源验证至少两套明显不同的编队能通关；不要求所有任意编队都能通关。
- 第一轮失败能解释为漏防、方向错误、技能时机、目标选择或资源分配；如果必须刷收藏或靠大量反复点击才能过去，回到关卡设计修正。
- 先验证无品质加成的第一关，再实现第二关组合，最后实现第三关方向变化与登船；单位规则与关卡一起落地，避免先全量增加能力再靠提高敌人血量补难度。
