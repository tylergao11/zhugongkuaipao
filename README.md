# 主公快跑 · 网页 MVP

运行 `npm start`，电脑打开 http://localhost:4173 。手机与电脑在同一 Wi-Fi 时，打开启动终端输出的局域网地址。静态文件也可部署到普通静态网页服务器，无需安装依赖、数据库或构建步骤。

## 2026-09-16 两关收口

- 只保留教学关「长坂逃命」和 BOSS 关「江津抢渡」。第二关「山道设伏」、等船防守、火油、绊马索已删除。
- 每个单位一个不可替代的动词：箭 = 弓箭手，抛射 = 投石车，贯穿 = 连弩车，挡 = 拒马，架枪 = 长枪兵，盾 = 刀盾兵，推 = 滚木，法术 = 诸葛亮，破盾 / 勾回 = 关羽，打断 = 张飞。
- 宝箱只剩 4 件：护阵蛇矛、钩镰刀、回风扇、烟幕罐。钩镰刀勾离刘备最近的敌人，扛人者优先。
- 局内升级：点已上阵单位 → 升级，1→2→3 级，每级生命与伤害 +30%，价格为单位价的 60% / 90%；2 级解锁专长（`content.js` `UNIT_PERKS`，数值在 `balance.js` `PERKS`）。拆卸退还（价格 + 升级费）的一半 × 剩余血量比。
- 脚底抹油是底部圆形按钮：3 秒、2.4 倍、冷却 30 秒，手动触发；被扛或骑马时不可用。
- BOSS 关按咬距放兵和放技能，不按时间。曹操进度过半从街口出现，碰到即负，不能被震晕或击退。血条只给曹操。
- 关卡设计见 [LEVEL-DESIGN.md](docs/LEVEL-DESIGN.md)，数值见 [BALANCE.md](docs/BALANCE.md)。

## 已实现范围

- 两个关卡、三层城楼，每层六个格子，共十八格。
- 刘备自动沿底层向右、中层向左、顶层向右的路线逃跑。
- 曹兵始终追捕刘备。抓到后扛人者押往当前失败点（街口 / 登岸口 / 栈道口），其余人清路；扛人者也被拒马和守军挡住。打死扛人者，刘备当场落地继续跑。
- 刘备到达顶层出口（BOSS 关为接应船）获胜。曹操抓住当场判负。
- 关羽、张飞、诸葛亮在场各限一个；弓箭手、拒马可重复部署。
- 一格一个驻守单位，放置后不可移动；阵亡后可花钱重新部署。点已部署单位可拆卸，返还原价 50% 军饷。
- 按住底部卡牌拖到格子，松手布防；滚木按拖放方向滚动，被扛时默认推离失败点。
- 开局军饷 180，BOSS 关再加 40，每秒恢复 4。音乐和音效随开局启用，可手动关闭。
- 暂停、重新开局、横屏全屏请求、竖屏阻挡与自动暂停。

## 战斗与动作

- 所有出场角色都有待机、受击、攻击或奔跑动作，驻守角色也会呼吸和改变重心。弓箭手蓄力后回弹，张飞踏地，关羽挥击，诸葛亮施法；同兵种待机错开节奏。守军在攻击冷却中也会朝新目标转身。
- 教学关用固定波次。BOSS 关追兵总数有限，按咬距分组出场，抓捕不刷新波次。界面显示场上与待援数量。
- 当前普攻与价格以 `assets/game/balance.js` 为准。箭和风弹飞抵目标后结算伤害。
- 张飞、关羽、诸葛亮技能由玩家点击已上阵卡牌释放，须有合法目标才进冷却。脚底抹油和护驾见下方。

## 视角、空降和护驾

- 手机默认放大战场，可按住战场拖动视角；顶部状态和底部卡牌固定。“全景”可看三层；手动平移后 3 秒无操作自动跟回刘备。拖卡到战场边缘会带动视角，拖放及拆卸使用相机坐标换算。
- BOSS 关伞兵只在「拉开」时投到刘备前方同层，落地前有预警；刘备跑过落点后它转为身后追兵，否则原地拦路。
- 刘备走上中层并拉开一次后，登岸口敌船靠岸；走上顶层并拉开一次后开放栈道口。入口后移，失败点跟着后移。曹彰与虎豹骑驻守登岸口，不追击、不占格。
- 右门开启时红屏警报、震感和文字提示同步出现。界面的“登岸口”按钮可定位新门。
- 曹彰驻守群像为 `assets/game/caozhang-cavalry-v1.webp`；母图与完整提示词见 `tools/art/CAOZHANG-GATE.md`。
- 远程射程按敌人体型边缘判定（半径 40），拒马不挡友军箭。均为同层远程单位，弹道到达后才结算伤害。
- 滚木冷却 10 秒，冷却中显示倒计时，重复拖放不扣钱。
- **护驾每局一次**，不消耗军饷，用后锁定，只有新开局恢复。赵子龙抱阿斗天降，0.8 秒后落地，对附近追兵造成伤害并眩晕 2 秒；刘备被抓时释放刘备。无营救无敌时间。赵云仅在大招登场，不占驻守格。
- 赵云透明素材为 `assets/game/zhaoyun-adou-v1.webp`；原图见 `tools/art/ZHAOYUN-ADOU.md`。伞兵的伞、预警、风弹与冲击波使用 Canvas 绘制。

## 背景音乐

原创循环曲《溜为上策》：130 BPM、32 小节、约 59 秒。使用合成拨弦、笛声音色、低战鼓、木质打击与沙锤，无人声和第三方音乐采样。

- 场景、将士与音乐一起预加载，加载页只显示总百分比。音乐下载并解码完成后才允许开局；加载失败停留在加载页，可重试。
- 点击开始游戏时解锁音频，确认音乐播放已启动后才开始战斗；音频未能解锁时保留开始页重试。右上角 `♫` 可同时关闭音乐和战斗音效。
- 战斗中循环播放；暂停、结算或切后台时停下，继续战斗从原位置恢复。关闭声音后，即使下载刚完成也不会自行播放。
- 运行文件 `assets/game/liu-run-bgm-v1.mp3` 约 925 KiB，32 kHz 立体声；通过 Web Audio 解码并循环。运行音量已降低以保留战斗音效。
- WAV 母带与音符谱位于 `output/audio/`；生成脚本 `tools/audio/compose-bgm.py`，依赖 NumPy、SciPy。音乐源素材不进入游戏首屏下载。
- 已验证音频解码、峰值无削波、循环源、暂停续播、关闭及加载期间关闭；微信真机声音仍需设备验收。
