# 主公快跑 · 网页 MVP

运行 `npm start`，电脑打开 http://localhost:4173 。手机与电脑在同一 Wi-Fi 时，打开启动终端输出的局域网地址。静态文件也可部署到普通静态网页服务器，无需安装依赖、数据库或构建步骤。

## 2026-09-16 收口：越简单越有趣

- 每个单位一个不可替代的动词：箭 = 弓箭手，抛射 = 投石车，贯穿 = 连弩车，挡 = 拒马，架枪 = 长枪兵，盾 = 刀盾兵，推 = 滚木，烧 = 火油，绊 = 绊马索，法术 = 诸葛亮，破盾 = 关羽，打断 = 张飞。删掉连弩兵、投石兵（重复）。
- 宝箱只剩 4 件：三件改变武将技能的兵器（护阵蛇矛、钩镰刀、回风扇）+ 烟幕罐。25 件侧移装备、诱敌旗、调兵令、第三关火油桶机关和"伏兵尽出"白送阵全部删除。
- 局内升级：点已上阵单位 → 升级，1→2→3 级，每级生命与伤害 +30%，价格为单位价的 60% / 90%；2 级解锁专长（`content.js` `UNIT_PERKS`，数值在 `balance.js` `PERKS`）。拆卸退还（价格 + 升级费）的一半 × 剩余血量比。
- 第三关曹操：刘备进度过半时从街口入口出生上行（`LEVEL_TUNING.river.caocao`），出场全军加速 8 秒；不能被震晕、击退，只能减速；他碰到刘备——无论刘备自由还是被押——当场判负。进度条上有红色"曹"标记，血条归他，打死给 100 金币。
- 美术 v3 素材（`assets/game/*-v3 / -v1.webp`、`tools/art/v3`、`docs/maps`）保留在仓库，代码尚未使用，留给后续。

## 已实现范围

- 一个关卡、三层城楼，每层六个格子，共十八格。
- 刘备自动沿底层向右、中层向左、顶层向右的路线逃跑。
- 曹兵始终追捕刘备，位于前方的追兵也会回身拦截。抓到刘备后暂停增援：扛人的押往入口或已开启的曹彰右门，其他曹兵优先攻击押送路线上的守军和拒马；路线清空后跟随押送者，不再自行跑向出口退场。只有扛人的抵达押送出口才失败。
- 击败扛人的曹兵会释放刘备，全体存活曹兵恢复追击，无营救保护时间。
- 刘备到达顶层出口获胜；被带回底层曹军入口，或被带到已开启的第二层右门时失败。
- 关羽、张飞、诸葛亮在场各限一个；弓箭手、拒马可重复部署。
- 一格一个驻守单位，放置后不可移动；阵亡后可花钱重新部署。点已部署单位可拆卸，返还原价 50% 军饷。
- 按住底部卡牌拖到格子，松手布防；点击卡牌或空格不放置。拖动时才显示可放位置，落点高亮；松手后隐藏提示，拖到无效位置取消且不扣钱。
- 滚木和火油拖到格子松手释放，可覆盖已有守军，不伤友军、不占驻守格。
- 军饷减半：开局 180、每秒增长 3.5、击杀奖励为原来 50%；卡牌价格不变，拆卸仍退原价 50%。音乐和音效随开局启用，可手动关闭。
- 暂停、重新开局、横屏全屏请求、竖屏阻挡与自动暂停。

## 战斗与动作

- 所有出场角色都有待机、受击、攻击或奔跑动作，驻守角色也会呼吸和改变重心。弓箭手蓄力后回弹，张飞踏地，关羽挥击，诸葛亮施法；同兵种待机错开节奏。守军在攻击冷却中也会朝新目标转身。
- 本关固定 24 名追兵分批出场，抓获刘备时暂停增援；界面显示场上与待援数量，最后一拨有提示。降低伤害后不再无限追加敌军，避免反复营救拖成无尽关卡。
- 当前普攻：弓箭手 15.6，关羽 26（普通攻击额外溅射一个目标，伤害为 55%），张飞 16，诸葛亮 7。滚木伤害 90，火油每秒 26。箭和风弹飞抵目标后结算伤害。三位武将技能伤害及已有控制的持续时间、击退距离上调 30%，弓箭手攻击力上调 30%；军饷维持当前数值。
- 武将技能自动释放，有目标才使用；卡牌显示技能冷却。手动救场道具和一次性护驾见下方。

## 视角、空降和护驾

- 手机默认放大战场，可按住战场拖动视角；顶部状态和底部卡牌固定。“全景”可看三层，“找主公”定位并跟随刘备；手动平移或拖卡时停止跟随。拖卡到战场边缘会带动视角，拖放及拆卸使用相机坐标换算。
- 24 名追兵分为 20 名地面兵、4 名油纸伞兵。逃脱进度首次到达 50% 解锁空降，约 2.4 秒后首波，之后间隔 10.5 秒。降落耗时 2.2 秒，有落点预警，空中不参与战斗。抓获刘备暂停新增援，已在空中的伞兵落地后加入清路和押送。
- 逃脱进度首次到达 50% 时，第二层最右侧开启曹彰右门。保留 8 名普通地面兵作为开门后的增援，后续地面兵（含新出场的统领）均从曹彰右门出发，原入口停止出兵；伞兵仍按空降规则落地。追兵总数仍为 24。曹彰与两名虎豹骑驻守，不追击、不占格、不计入追兵。敌人扛着刘备到门口立即失败；普通敌人和自由的刘备经过不触发失败。开门后进度回退不会关门，重新开局才重置。
- 右门开启时红屏警报、震感和文字提示同步出现，之后保留淡红边缘；刘备被抓后红边加重并缓慢闪动。界面的“街市右门”按钮可定位新门；警报不阻挡拖放操作，降低动态效果设置会关闭闪动。
- 曹彰驻守群像为 `assets/game/caozhang-cavalry-v1.webp`，512×384，74,538 字节；母图与完整提示词见 `tools/art/CAOZHANG-GATE.md`。驻守呼吸、开门、红色预警均使用代码动画。
- 弓箭手射程 370、诸葛亮射程 580，远程射程按敌人体型边缘判定（半径 40），拒马不挡友军箭；弓箭手隔两格也能射中被拒马挡住的追兵。均为同层远程单位，弹道到达后才结算伤害。诸葛亮发射风弹，东风在远处目标位置爆发并吹退周围敌人。
- 滚木冷却 6 秒、火油冷却 8 秒，冷却中显示倒计时，重复拖放不扣钱。
- **护驾每局一次**，不消耗军饷，用后锁定，只有新开局恢复。赵子龙抱阿斗天降，0.8 秒后落地，对附近追兵造成 55 法术伤害、震晕 3 秒并破盾；刘备被抓时释放刘备。无营救无敌时间。赵云仅在大招登场，不占驻守格。
- 赵云透明素材为 `assets/game/zhaoyun-adou-v1.webp`，512×512，76,330 字节；内置 imagegen 生成，原图和完整提示词见 `tools/art/ZHAOYUN-ADOU.md`。伞兵的伞、预警、风弹与冲击波使用 Canvas 绘制。
- 验证：844×390 与 667×320 浏览器尺寸下的拖动、全景、拖卡、冷却、拆卸、护驾次数恢复；内联规则校验包含空降阈值、降落与撤退、远程命中及军饷，24 人完整对局模拟可通关。没有创建测试代码文件；微信真机尚未验收。

## 背景音乐

原创循环曲《溜为上策》：130 BPM、32 小节、约 59 秒。使用合成拨弦、笛声音色、低战鼓、木质打击与沙锤，无人声和第三方音乐采样。

- 场景、将士与音乐一起预加载，加载页只显示总百分比。音乐下载并解码完成后才允许开局；加载失败停留在加载页，可重试。
- 点击开始游戏时解锁音频，确认音乐播放已启动后才开始战斗；音频未能解锁时保留开始页重试。右上角 `♫` 可同时关闭音乐和战斗音效。
- 战斗中循环播放；暂停、结算或切后台时停下，继续战斗从原位置恢复。关闭声音后，即使下载刚完成也不会自行播放。
- 运行文件 `assets/game/liu-run-bgm-v1.mp3` 约 925 KiB，32 kHz 立体声；通过 Web Audio 解码并循环。运行音量已降低以保留战斗音效。
- WAV 母带与音符谱位于 `output/audio/`；生成脚本 `tools/audio/compose-bgm.py`，依赖 NumPy、SciPy。音乐源素材不进入游戏首屏下载。
- 已验证音频解码、峰值无削波、循环源、暂停续播、关闭及加载期间关闭；微信真机声音仍需设备验收。
