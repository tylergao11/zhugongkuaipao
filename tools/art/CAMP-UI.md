# 长坂大营 UI · 渲染设计接入

当前完整清理记录见 [UI-CLEANUP.md](UI-CLEANUP.md)。

## 设计来源

- 用户认可首页：output/camp-home-approved-v1.png；页面设计：output/camp-ui-design-v1.png。设计卡面仅供视觉参考，可用名单来自程序数据。
- 首页保留整幅场景、人物、标题与按钮底板，金币和按钮文字作为可变层。返回/「刘备阵营」已从底图移除，Logo 左移。
- 按钮、纸张、卡框、金币和宝箱均从认可的渲染设计派生；人物复用现有图集。完整历史制作提示词见 camp-ui-prompts.json。

## 页面与接口

- 首页两个主要入口：宝箱、编队。设置为小型辅助按钮，无独立装配、情报或奖池概率页面。
- 编队最多六格，点空位进入独立选人页，点人物进入详情，装卸在详情内。其他任务新加的编队卸下按钮和养成功能继续保留。
- 删除选人、换人、装卸的重复说明文字。价格、属性、品质、技能冷却和操作按钮按程序数据显示。
- camp.js 管交互，camp-ui.css 仅管营地视觉；战斗、结算、加载器分别由独立样式表负责，禁止恢复旧绿色通用面板。
- 开箱动画只展示 profile.openChest() 已返回的结果，不二次抽取或扣费。
