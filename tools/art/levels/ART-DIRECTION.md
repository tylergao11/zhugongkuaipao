## 统一视觉与场景结构

- 沿用现有浓墨轮廓、手绘木石纹理、夸张三国角色。背景细节稍收，人物与可交互物有完整轮廓；不改成写实、3D 或圆脸幼儿画风。
- 第一关偏土黄、火光；第二关偏松绿、青灰山石；第三关偏暮蓝、江水与暖灯。三关共用蜀军绿色／曹军红黑色，换关不换阵营识别。
- 继续使用 1440×810 世界坐标，三层脚底基准从下到上为 y=665、433、236。背景按整幅映射，底右楼梯、中左楼梯分别接续现有折返路线。
- 1672×941 母图中，基准线约为 y=773、503、274。画面已按该结构绘制；道路有纹理和厚度，接入时必须以实际演员脚底叠图检查，不能把平台底梁当作脚底地面。
- 每层原有六个部署点沿用 `SLOTS`，不把格子和光圈画进背景。兵种站立的区域保留低对比色块；前景植物、绳栏和梁柱不能挡住脚、血条、拖拽落点。
- 背景不包含可消耗机关、正在停泊的船、武将、倒计时、引导箭头和文字。这样开关机关、来船和离船都有真实视觉变化。
- 地图新机关独立于驻守格，不让一处机关装饰看起来像可部署空格，也不让装饰山石像可点击落石。

## 第二关：山道设伏

构图：下层是山脚土路，上方可见窄谷与雾；中层是跨峡木栈道和岩壁隘口；上层是山顶关隘。场景纵深在人物背后，主路保持水平。远处山峰不做动画，雾只做很淡的背景运动，避免抢走落石预警的注意力。

重点物件为有绳扣与绿色拉柄的落石架，以及能被曹兵扛走的假刘备。假主公必须看得出是木偶：缝线脸、稻草手脚、假胡子，绿袍只负责远看像刘备，不能照搬真人精灵。

设计图按从左到右、从上到下排列：

| 标识 | 图中位置 | 需要的状态与拆分 | 画面中的用途 |
| --- | --- | --- | --- |
| `rockfall_cradle` | 左上 | 装填状态，木架、锁扣、拉柄可拆；底部支点保持一致 | 中层岩壁侧的机关，离开行走与驻守带 |
| `rockfall_cradle_spent` | 中上 | 空架、开闸状态；与装填状态同尺度同锚点 | 释放后明确变空，不能只把整件变灰 |
| `rockfall_boulder` | 右上 | 独立滚石；中心为旋转锚点 | 从架中落下，再按逻辑路径滚动，碎屑由代码生成 |
| `decoy_liubei` | 左下 | 站立、被扛、丢落；躯干、双臂、草脚适合独立摆动 | 站立时有轻微稻草摆动，被扛时横放，不能带着底座飞走 |
| `decoy_spent` | 中下 | 散落假胡子、绿布与稻草 | 被识破后显示耗尽；提示结束后消失，避免误认活单位 |
| `bounty_standard` | 右下 | 旗杆／旗面；高亮、悬赏结束 | 曹洪发令时显示钱币图样，标识抓捕手；悬赏取消时收旗 |

建议布置区域是中层偏右岩壁的独立机关凹位、上层道路后沿的木偶激活点；最终触发范围和坐标由关卡定义管理，不由图片决定。机关预览绘制完整滚动方向，出现携带者时也要看得见会被推向哪边。

落石表现顺序：拉柄可点击 → 点击后绳扣松开 → 石头下落／滚动 → 短促尘土 → 空架留在原地。木偶表现顺序：未激活无诱导效果 → 激活后绿布立起 → 敌兵扛走 → 到入口后识破散架。状态显示由游戏事件驱动，不用贴图动画结束时间决定伤害或胜负。

## 第三关：江津抢渡

构图：下层石堤与临江仓房，中层木质沿岸栈道，上层渡口。蓝灰江水与暖色灯笼形成反差；行走地面保持浅棕色，避免黑色曹兵淹没在夜色里。

中层右端预留敌船靠岸区，对应原侧门语义；上层右端预留接应船区。船在背景后方驶近，然后进入独立前后分层。可以让部分船身自然伸出画面右侧，不压缩最后两个驻守位给船腾位置。

设计图按从左到右、从上到下排列：

| 标识 | 图中位置 | 外形与状态 | 必须拆开的部分 |
| --- | --- | --- | --- |
| `enemy_landing_barge` | 左上 | 红黑低舷战船、虎首船头、空甲板；远处、驶近、靠岸、开放接收点 | 后侧船体与甲板、前侧船舷、旗帜；曹彰和骑兵使用现有独立群像 |
| `friendly_ferry` | 右上 | 绿篷、金棕船身、暖灯，船头留空；驶近、等待、允许登船、载人离开 | 篷与后舷、前舷、绿旗／灯笼；刘备使用现有角色，不画死在船上 |
| `boarding_gangway` | 中左 | 独立木板跳板；收起、放下、收回 | 支点明确，靠岸时旋转落下；脚步连接点由关卡与船的锚点共同决定 |
| `landing_marker` | 中右 | 红色虎纹靠岸旗；预警、入口开放、押送危险 | 静态旗座与可摆动旗面，警告轮廓由代码叠加 |
| `parachute_intact` | 左下 | 完整油纸伞及绳索；下落、受风、被命中 | 伞面／伞骨、吊绳；底部吊点挂已有曹兵 |
| `parachute_torn` | 右下 | 破伞与断绳；伞被击破、落地散落 | 与完整伞共用伞顶和吊点参考，断片少而清楚 |

母图的两只船均以前端朝左的视角绘制。接入时可用无文字素材的镜像或运动方向处理接应船离开，不把原提示词中的“朝右”当作已完成结果。船只必须按水线／甲板锚点定位，不能按透明画布底部直接放到 y=433 或 236。

敌船顺序：远处船影 → 红旗与泊位预警 → 靠岸 → 跳板放下 → 援军出现。靠岸前不画出可以送人的有效出口。接应船顺序：等待进度开始 → 远处逐渐靠近 → 靠岸放板 → 刘备登船 → 收板离开。敌我船均有颜色之外的轮廓区分：敌船无篷、虎首；友船有绿篷、灯笼。

空降顺序：落点轮廓与吊绳影 → 完整伞下落 → 被射中则换破伞并触发失衡落地 → 收伞消失。诸葛亮改落点时，预警必须跟随真正落点移动，不能保留错误旧标记。

调兵令、诱敌旗、烟幕罐三张共用计策的图标分别采用调动箭头令牌、绿色诱敌旗、带烟口陶罐；动作箭头和烟幕范围由代码绘制。它们属于全局宝箱资源，造型沿用本关风格，不作为地图里已经免费的机关重复收费。

## 拆图与接入规范

- 背景目标运行版约 1672×941 WebP，另出 560×315 关卡缩略图；导出质量通过目视决定，单图约 300–500 KiB 为目标而非本次已测结果。
- 道具拆件使用真 alpha PNG 母图和 alpha WebP 运行图。纯色底与棋盘格不算透明；须实际读出 alpha，并在深／浅背景上检查白边、灰格与半透明细绳。
- 岩架两个状态用同画布、同支点；滚石用中心；木偶用脚底，扛人姿态另设肩部挂点；船用甲板和水线双锚点；伞用伞顶和吊点。实际裁切矩形与锚点由拆图后的资源清单记录，不按本设计稿的等分格盲切。
- 船的绘制顺序是远景水面 → 船后部／甲板 → 曹彰或刘备 → 前船舷／跳板前缘 → 提示。背景上已有的静态栏杆不能遮住角色脚底。
- 木偶不是新英雄，不能占普通驻守卡位或使用真人刘备的胜负状态；旗帜和船同样只表现所属机制，不自行计算抓捕和通关。
- 第二关加载自己的背景和机关，第三关加载自己的背景和船伞；角色图集共用。母图留在 `tools/art/levels`，未经拆图、压缩、接入的设计稿不进入游戏首屏下载。
- 接入验收重点是三层脚底、18 格拖放不遮挡、船在到达前不存在接收点、敌我船可辨、落石已耗尽、木偶被扛与真人被扛可辨，以及伞落点受风后预警一致。本轮没有宣称这些运行验收已完成。
